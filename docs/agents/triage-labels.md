# 问题分诊标签映射 (Triage Labels)

工程技能遵循五个标准分诊角色。本文件将这些标准角色映射为当前仓库 Issue Tracker 中实际使用的标签字符串：

| mattpocock/skills 标准角色 | 当前仓库使用的标签 | 含义说明 |
| :------------------------- | :----------------- | :------- |
| `needs-triage`             | `needs-triage`     | 待维护者评估与分诊 |
| `needs-info`               | `needs-info`       | 等待反馈者提供更多排查信息 |
| `ready-for-agent`          | `ready-for-agent`  | 需求规格完备，可由 AI 智能体独立认领执行 |
| `ready-for-human`          | `ready-for-human`  | 需人类开发者介入实现 |
| `wontfix`                  | `wontfix`          | 决定不予处理或关闭 |

当技能要求应用分诊角色（如“打上 AFK-ready 标签”）时，直接使用本表格右侧对应的标签字符串。
若后续调整了项目标签规范，可直接修改本表右侧一列。
